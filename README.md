# 여행 속도계 · Kids Trip Speedometer

아이와 보호자가 함께 보는 Android 여행 앱. 개발 버전 **0.5.0**.

[0.5.0 개발용 APK](downloads/travel-speedometer-0.5.0-debug.apk)를 GitHub에서 열고 **Download raw file**로 받는다. 기존 앱 위에 업데이트 설치한다.
Android 8.0(API26) 이상. 비공개 저장소라면 권한이 있는 GitHub 계정 로그인이 필요하다.

## 화면과 기능

- 여행: 큰 GPS 속도, 현재 도시, 이동 방향, 전체 ODO / 리셋 후 TRIP / 이번 실행 거리.
- 방향은 기본 GPS 진행 방향(진북 기준). 정지·저속·불안정한 신호에는 ‘이동하면 표시해요’. 보호자 설정에서 휴대폰 방향(자북) 모드도 선택할 수 있다.
- 탐험: 강·산·다리·터널·들판·도시 질문 6종, 찾았어요와 다음 카드. 위치·인터넷 없이도 사용할 수 있고 발견은 누적 보관한다.
- 도장 보관함: 한 줄 4칸, 도시 배지와 방문 횟수. 첫 방문과 확인된 재방문마다 소리·효과가 나온다. 같은 도시는 한 칸으로 유지한다.
- 도시 확인은 최소 1분 간격의 두 번 관측이 필요하다. 5분 위치 캐시는 제거했다. 앱을 끄고 이동한 방문은 추정하지 않고, 같은 도시에 다시 앱을 열었다고 방문 수를 늘리지 않는다.
- 소리: 도시 멜로디·맑은 종소리·반짝반짝 3종 선택/미리듣기. 미디어 음량 사용, 무음·방해금지 존중. 소리가 막힌 이유를 설정 아래에 표시한다.
- 자동으로 화면 꺼짐 방지. 앱을 벗어나면 기본 화면 꺼짐 설정을 따른다.

## 내 휴대폰에 계속 보관

앱 전용 로컬 저장소에 도장, 방문 횟수, 발견, 선택한 소리/방향/효과, ODO/TRIP을 저장한다.
업데이트·재실행 후 유지되며 **새 여행/도장 전체 초기화 버튼은 없다**. `TRIP 초기화`는 거리 하나만 지운다.

| 거리 | 의미 |
|---|---|
| 전체 ODO | 이 버전의 기록 시작 이후 앱 사용 중 측정한 전체 거리, 초기화하지 않음 |
| 리셋 후 TRIP | 마지막 TRIP 초기화 이후 거리, 앱 재시작 후에도 유지 |
| 이번 실행 | 이번 앱 실행의 거리, 회전/잠깐 다른 앱 이동은 유지, 새 실행에서 0 |

GPS 오차·점프·정지 흔들림·오래된 점·15초 넘는 수신 간격은 거리에서 제외한다. 앱이 배경에 있을 때의 구간은 잇지 않는다.
자동차 계기판과 같은 정밀 거리계가 아니라 대략적인 GPS 거리다.

좌표·이동 경로를 파일에 저장하거나 앱 서버로 전송하지 않는다. 도시명 조회는 Android Geocoder의 시스템 서비스/인터넷을 사용할 수 있다.
기존 0.4.x는 컬렉션을 저장하지 않았으므로 이미 사라진 과거 기록을 복구할 수 없다.
앱을 삭제하거나 Android에서 앱 데이터를 지우면 로컬 기록도 지워진다. 자동 클라우드 백업은 비활성화했다.

## 도시 그림

현재는 **앱 전용 창작 여행 배지**다. 공식 지자체 로고가 아니다.
서울·수원·용인·성남·인천·춘천·강릉·원주·대전·세종·청주·천안 12개를 앱에 포함했다.
등록하지 않은 지역에는 ‘로고 준비 중’을 표시한다. 검색 결과를 도시 변경 때 무작위로 내려받지 않는다.
원본/매핑/출처 규칙: [city_logos README](app/src/main/assets/city_logos/README.md).

## 개발·검증

JDK17/21, SDK35, AGP8.9.1, Gradle8.11.1. Android Studio에서 열거나:

```sh
./gradlew --no-daemon testDebugUnitTest assembleDebug lintDebug
```

Windows: `./gradlew.bat testDebugUnitTest assembleDebug lintDebug`.
클라우드 도구가 없으면 `bash scripts/cloud-setup.sh`.
APK: `app/build/outputs/apk/debug/app-debug.apk`.

0.5.0은 자동 테스트 **96개**, 빌드·lint(오류·경고 0)를 통과했다. 구체적인 APK 해시·휴대폰 확인 순서는 [downloads/README.md](downloads/README.md).
실제 GPS·차량 이동 방향·거리 정확도·기기 스피커·작은 화면/큰 글꼴은 실기기에서 확인해야 한다.
