# 여행 속도계 · Kids Trip Speedometer

아이와 보호자가 이동 중 속도와 현재 도시를 함께 보는 Android 앱. 현재 개발 버전은 **0.3.0**이다.
Android 8.0(API 26) 이상, Java 17 소스, Android Gradle Plugin 8.9.1, Gradle 8.11.1, SDK 35.

## 구현 범위

- GPS 속도를 km/h로 변환해 큰 글씨로 표시한다. 오른쪽에 센서 기반 나침반(화면 위쪽 방향·자북 기준)을 함께 표시한다. 나침반은 GPS 이동 방향과 다르며, 센서가 없어도 다른 기능은 사용할 수 있다.
- 최근 10초 이내 GPS 관측만 사용한다. 속도 없음/정확도 낮음은 0 대신 ‘—’로 표시한다.
- Android Geocoder로 도시를 조회한다. 도시가 없으면 시군 또는 광역 행정명으로 대체한다.
- 역지오코딩은 최소 60초 간격이다. 도장 확인 대기 중에는 같은 장소도 다시 조회한다. 확인 대기가 없고 이전 성공 위치와 1km 미만이면 최대 5분 캐시한다.
- 권한 거부, 대략적 위치만 허용, GPS 꺼짐, GPS 미지원, 신호 단절, 도시 조회 실패를 안내한다.
- 여행·탐험·도장 탭으로 화면을 전환한다. 화면을 벗어나 다른 앱으로 가면 GPS 구독을 해제한다.
- 강·산·다리·터널·들판·도시 탐험 카드 6종: 질문과 짧은 설명, 직접 ‘찾았어요’, 중복 집계 방지, 다음 카드. 인터넷/위치 권한 없이도 이용한다.
- 도시 도장: 도시가 1분 이상 간격으로 두 번 연속 확인되면 한 번 수집한다. 도시가 바뀌거나 GPS가 끊기거나 앱이 배경으로 가면 확인 대기를 초기화한다. 같은 도시는 중복 수집하지 않는다. 광역 행정명만 알 수 있는 경우에는 도장을 주지 않는다.
- 도장과 카드 발견은 메모리에만 유지한다. 화면 회전은 유지하지만 앱 종료/프로세스 종료/‘새 여행 시작’ 확인 후에는 지운다. 좌표·경로·방문 시각을 파일이나 서버에 보관하지 않는다.
- 로그인, 광고, 분석 SDK, 서버, 백그라운드 위치 추적은 없다.
- Geocoder는 기기에 구현된 시스템 서비스를 이용한다. 도시 조회에는 네트워크 및 서비스 제공자 처리가 발생할 수 있고, 오프라인 도시명은 보장하지 않는다.

## 빌드

Android Studio에서 이 폴더를 열고 SDK 35를 설치한 다음 실행한다.
커맨드라인에서는 JDK 17 또는 21, Android SDK가 필요하다.

```sh
./gradlew testDebugUnitTest assembleDebug lintDebug
```

Windows PowerShell에서는 `./gradlew.bat testDebugUnitTest assembleDebug lintDebug`.
APK: `app/build/outputs/apk/debug/app-debug.apk` (개발용 서명).
실제 위치·속도 검증은 Android 기기에서 위치 권한을 허용하고 수행한다.
클라우드는 빌드와 단위 테스트를 담당하며 실제 GPS 수신을 검증하지 못한다.

## 수동 검증

1. 첫 실행: 위치 사용 버튼으로 정확한 위치 허용. GPS 수신 후 속도·도시 표시 확인.
2. 권한 거부 또는 대략적 위치만 허용: 정확한 위치 안내, 충돌 없음 확인.
3. GPS 끄기/터널 진입: 10초 내 속도가 ‘—’로 바뀌고 오래된 도시를 현 위치처럼 표시하지 않는지 확인.
4. 네트워크 끄기: 속도 측정은 지속, 도시 조회 실패 안내 확인(시스템 캐시 결과가 나올 수도 있음).
5. 홈 버튼/다른 앱 이동: GPS 구독 해제, 복귀 시 재수신 확인.
6. 회전·큰 글꼴·작은 화면·Android 15 시스템 바 겹침 확인.
7. 탐험 탭: ‘찾았어요’로 1개 증가, 같은 카드 중복 없음, 다음 카드/6종 순환 확인. GPS·인터넷을 끄고도 조작 가능.
8. 도장 탭: GPS가 잘 잡히는 한 도시에서 화면을 1~2분 이상 켜 두고 첫 도장 확인. 도시 변경/경계 흔들림/중복 확인.
9. 회전하면 카드·도장은 유지되는지 확인. ‘새 여행 시작’ 취소는 유지, 확인은 모두 삭제. 앱 완전 종료 후 다시 열면 빈 여행인지 확인.
10. 도시 경계 통과, 정지, 이동, 장시간 이동, 배터리 소모는 실제 동승 테스트 필요.

추가 놀이 요소 검토: [docs/playful-learning.md](docs/playful-learning.md).

## 나침반 사용

나침반은 화면 위쪽의 자북 기준 방위를 표시한다. 휴대폰을 조금 평평하게 놓고 사용한다.
세로·가로 화면에 맞춰 축을 보정하고, 정확도 낮음/센서 없음/값이 오래됨을 구분한다.
차량 금속·자석의 영향을 받으므로 실제 방위 확인은 자기장 간섭이 적은 곳에서도 수행한다.
새 런타임 권한이나 외부 서비스를 추가하지 않고, 화면을 벗어나면 센서 수신을 해제한다.
