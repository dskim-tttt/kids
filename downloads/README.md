## 도시 환영 효과

- 새 도시 도장이 확정되면 도시 이름 배지가 크게 나타나고 짧은 색종이 효과와 0.75초 알림음이 재생된다.
- 도시 이름·색·풍경을 조합한 앱 자체 배지다. 공식 지자체 로고나 실제 랜드마크를 나타내지는 않는다.
- 기존 조건 유지: 같은 도시를 1분 이상 간격으로 두 번 확인한 후 한 번 수집. GPS 경계 오인식을 줄이기 위한 조건이며 진입 즉시 재생을 보장하지 않는다.
- 같은 도시 중복 조회, 실패한 조회, 배경에서 도착한 늦은 응답에는 연출하지 않는다.
- 약 4.5초 뒤 닫힘, ‘계속 여행하기’로 즉시 닫기. 화면 읽기 기능 사용 중에는 직접 닫을 때까지 유지한다.
- 다른 앱으로 이동하면 소리·애니메이션·자동 닫기 타이머를 정리한다.
- 여행 화면 하단 보호자 설정에 소리/움직임 스위치와 ‘도시 환영 효과 미리보기’ 버튼을 제공한다. 미리보기는 도장을 주지 않는다.
- 소리·움직임은 기본 켜짐. 기기 무음·진동·방해금지·시스템 음량 0을 존중하고 시스템 애니메이션 비활성화 설정을 따른다.
- 소리·움직임 선택 두 개만 기기에 저장한다. 도시 도장·발견·좌표·이동 경로는 영구 보관하지 않는다.
- 도장 목록에도 동일한 도시 배지를 표시한다.

## 검증

- 자동 테스트 **44개 통과**, 실패/오류/건너뜀 0.
- 신규 도시/중복/실패 조회, 미리보기 무보상, 자동 닫기, 배경 전환, 설정 유지, 음원 재생/종료/무음·방해금지 억제를 검증했다.
- APK 빌드 및 lint 통과(오류·경고 0), 서명·압축 무결성 확인. 기존 0.3.0과 서명 인증서 일치.
- 직접 생성한 WAV 음원을 비압축 상태로 APK에 포함한 것을 확인했다.
- 휴대폰에서의 실제 소리·애니메이션·업데이트 설치는 미검증이다.

## 휴대폰에서 확인

1. 기존 앱 위에 업데이트 설치.
2. 여행 화면 아래 ‘보호자와 함께 설정해요’ → ‘도시 환영 효과 미리보기’로 배지·소리·색종이 확인.
3. 소리 끄기, 움직임 끄기, 휴대폰 무음·방해금지·시스템 음량 설정을 바꿔 확인.
4. 다른 앱으로 이동하면 소리가 중단되고, 다시 돌아와도 효과가 반복되지 않는지 확인.
5. 실제 새 도시에서 도장이 확정되면 1회 연출되는지 확인. 기존 속도·도시·나침반·카드 기능도 확인.
