## 이번 변경

1. 소리: 시스템 효과음 대신 미디어 음량 사용. 도시 멜로디·맑은 종소리·반짝반짝 선택과 명시적 미리듣기. 무음·방해금지·음량·재생 실패 이유를 실시간 표시.
2. 누적 기록: 도장·방문 횟수·발견·설정·ODO/TRIP을 휴대폰 앱 전용 로컬 저장소에 보관. 앱 재시작/업데이트 후 유지. 앱 서버로 보내지 않는다.
3. 새 여행/도장 전체 삭제 버튼 제거. TRIP 거리만 확인 후 초기화한다. ODO·이번 실행·도장·방문은 유지.
4. 도장 보관함 4열과 방문 횟수. 앱 자체 도시 여행 배지 12종을 포함하고 공식 지자체 로고와 구분한다. 나머지 지역은 준비 중.
5. 기본 나침반은 GPS 이동 방향(진북). 정지·저속·불안정 시 대기. 휴대폰 자북 방향은 설정에서 선택 가능.
6. 전체 ODO / 리셋 후 TRIP / 이번 실행 거리 표시. GPS 오차·점프·끊긴 구간·정지 흔들림을 제외한다.
7. 도시 조회를 5분 미루던 조건 제거. 서울·광역시 등 locality가 생략될 수 있는 도시와 이름 별칭을 보정한다. 도시 방문 확정에는 여전히 최소 1분 간격의 두 번 확인이 필요하다.
8. 화면 켜짐 유지, 첫 방문/재방문 소리·효과, 탐험 카드 기능 유지.

도장/방문은 앱 사용 중 확인된 것만 기록한다. 앱이 꺼져 있는 동안의 이동·방문은 추정하지 않는다.
이전 버전은 컬렉션/거리를 저장하지 않았으므로 이미 사라진 과거 기록은 복구할 수 없다.
자동 앱 백업은 꺼져 있다. 일반 업데이트는 보존하지만 앱 삭제·앱 데이터 지우기는 로컬 기록을 지운다.
Geocoder는 Android 시스템 서비스/인터넷을 사용할 수 있으나 앱 자체 기록 저장은 로컬이다. 좌표·경로는 파일에 저장하지 않는다.

## 검증

- 자동 테스트 **96개 통과**, 실패/오류/건너뜀 0; APK 빌드·lint 오류/경고 0.
- 새 Activity/로컬 저장 재로드, 누적 방문 보존·중복 방지·손상 보호, 4열 방문 수, TRIP만 초기화 검증.
- GPS 이동 방향·정지/저속/오래된 신호·끊긴 거리 구간·ODO/TRIP 보존, 소리 선택 유지·미디어 음량 회복·비동기 재생 오류 표시 검증.
- 실제 등록된 12개 배지의 이미지 디코딩과 도시 키 연결, 3종 WAV의 APK 포함 및 비압축 저장 확인.
- 이전 버전과 서명 일치, versionCode 증가, APK 압축 무결성 확인.
- 실제 휴대폰 음량·GPS 방향·거리 정확도·작은 화면/큰 글꼴·업데이트 설치는 추가 확인이 필요하다.

## 휴대폰 확인 순서

1. 기존 앱 위에 설치. 여행 화면 아래 보호자 설정에서 소리 3종을 선택하고 ‘선택한 소리 미리듣기’. 안 들리면 그 아래 차단 이유와 미디어 음량 확인.
2. 이동 중 폰을 돌려도 GPS 이동 방향이 차량 진행 방향을 유지하는지, 정지하면 대기로 바뀌는지 확인.
3. ODO/TRIP이 이동에 따라 늘고 앱 재실행 후 남는지 확인. TRIP만 초기화해 ODO/도장이 보존되는지 확인.
4. 새 도시를 충분히 확인해 도장/방문 수 증가, 앱 재실행 후 보존, 같은 도시 단순 재실행은 방문 수가 늘지 않는지 확인.
5. 4열 보관함과 12개 도시의 ‘여행 배지’, 큰 글꼴·가로 화면·화면 켜짐 유지 확인.
