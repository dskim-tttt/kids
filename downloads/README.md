## 0.3.0 변경

- 속도계 오른쪽에 휴대폰 나침반과 8방위·각도 표시를 추가.
- 화면 위쪽이 향한 자북 기준 방위다. GPS로 계산한 차량 이동 방향과는 다르다.
- 회전 벡터 센서 사용, 지원하지 않으면 지자기 회전 벡터 또는 가속도+자기장 센서로 대체.
- 센서 없음, 정확도 낮음, 휴대폰이 너무 세워져 방위가 불명확함, 오래된 센서 값은 별도 안내.
- 화면 회전에 따라 축 보정. 다른 앱으로 나가면 센서 구독 중지. 추가 권한이나 기록 저장 없음.
- 기존 속도·도시·탐험 카드 6종·실행 중 도시 도장 기능 유지.

## 휴대폰 확인 순서

1. 기존 앱 위에 업데이트 설치.
2. 휴대폰을 조금 평평하게 놓고 방향을 천천히 바꾸며 바늘/방위가 변하는지 확인.
3. 세로·가로 화면에서 화면 위쪽을 기준으로 표시하는지 확인.
4. 센서가 없는 기기의 안내와 금속/자석 근처 정확도 안내 확인.
5. 다른 앱으로 이동 후 복귀하면 새로 방향을 수신하는지 확인.
6. 속도·도시·탐험 카드·도장 기능 회귀 확인.
