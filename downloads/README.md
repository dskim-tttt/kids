## 재방문도 환영하기

- 수원 → 용인 → 수원처럼 다른 도시가 확정된 후 돌아오면 소리·배지·색종이를 다시 재생한다.
- 재방문에는 ‘다시 만난 도시!’ / ‘다시 와서 반가워요!’ 문구를 사용한다.
- 도장 목록은 도시당 한 개를 유지한다. 수원 → 용인 → 수원의 도장은 두 개다.
- 같은 도시에서 계속 GPS가 갱신되거나, 배경 전환/회전 후 같은 도시에 있으면 반복하지 않는다.
- 도시가 1분 이상 간격으로 두 번 확인되어야 한다. 확인되지 않은 이웃 도시·GPS 흔들림은 재방문으로 처리하지 않는다.
- 새 여행을 시작하면 도시 방문 상태·도장을 초기화하여 같은 시작 도시도 다시 환영한다.
- 이전 버전의 소리/움직임 설정, 무음·방해금지·볼륨 존중, 미리보기 무보상, 배경 전환 정리는 유지한다.

## 로고 상태

현재 배지는 앱 자체 도시 이름 배지다. 별도 도시별 로고 세트는 아직 원본이 없어 반영하지 않았다. 원본 로고와 도시 이름 매핑이 필요하다.
