## 이번 버전

- 여행·탐험·도장 탭, 크림색·청록색 화면과 앱 내 풍경 삽화.
- 강·산·다리·터널·들판·도시 카드 6종. 찾았어요, 다음 카드, 중복 집계 방지.
- GPS/권한/인터넷 없이 탐험 카드를 사용할 수 있다.
- 같은 도시가 최소 1분 간격으로 두 번 확인되면 도장 수집. 중복 도시/불안정한 관측은 제외.
- 실행 중 메모리에만 도장·발견을 유지. 회전은 유지, 앱 완전 종료나 새 여행 시작 시 초기화.
- 새 여행 시작에는 삭제 확인이 있다. 좌표·이동 경로 파일 저장이나 외부 전송 기능은 추가하지 않았다.

## 휴대폰에서 확인할 것

1. 삭제하지 않고 기존 앱 위에 업데이트 설치되는지 확인.
2. 탐험: 찾았어요 → 다음 카드 → 원래 카드로 돌아와 중복 집계 없는지 확인.
3. GPS가 잘 잡히는 곳에서 앱을 켜두고 같은 도시가 두 번 확인될 때 첫 도장 확인(약 1~2분 이상).
4. 새 여행 시작: 취소하면 유지, 확인하면 도장과 카드 발견이 지워지는지 확인.
5. 화면 회전 시 유지, 앱 완전 종료 후 다시 열면 초기화되는지 확인.
