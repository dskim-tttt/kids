# 0.5.0 화면 검토

[배치 시안](design-v0.5-proposal.png)은 디자인 검토용이며 실제 앱 화면의 캡처는 아니다.

- 크림색 #F6F3E9, 짙은 청록 #17413E, 행동 색 #246B64, 발견 카드 노랑 #FFCE69.
- 첫 화면: 속도와 GPS 이동 방향 → 현 도시 → 전체 ODO/TRIP/이번 실행 → 탐험 카드. 보호자 설정은 스크롤 아래.
- 이동 방향은 차량이 움직이는 GPS 진북 기준이다. 정지/저속에서는 기다림 표시. 설정을 끄면 기존 휴대폰 자북 방향 모드.
- ODO와 TRIP은 영구 보관하되 TRIP만 초기화. 도장/발견 삭제 버튼은 제거했다.
- 보관함: 4열, 약 52dp 그림, 도시명 14sp(2줄 허용), 방문 횟수 14sp. 전체 이름과 횟수는 접근성 라벨/누르기에서 확인.
- 실제 12개 도시 그림은 앱 전용 창작 여행 배지이며 공식 지자체 표장이 아니다. 등록하지 않은 지역은 준비 중.
- 도시 환영: 첫 방문/재방문마다 배지와 짧은 소리·색종이. 중복 도장은 만들지 않고 방문 횟수만 증가.
- 소리 3종 선택/미리듣기, 기기 무음·방해금지·미디어 음량 상태 설명. 시스템/사용자의 동작 줄이기 선택을 존중.
- 도장/방문/발견/거리/설정은 휴대폰 앱 전용 저장소에 유지. 앱 서버/상세 좌표 경로 저장은 없다.

검토 순서: 배치와 글자 크기 → 작은 화면과 큰 글꼴 → 배지 그림 스타일 → 색과 애니메이션.
공식 로고를 추가하려면 현재 판본과 사용허락/출처를 확인해 별도 등록한다. 이미지 검색 결과를 공식 로고라고 자동 채택하지 않는다.
