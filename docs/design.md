# 여행 속도계 디자인 제안

이 문서는 디자인 방향이며 현재 Android 초기 화면과 완전히 일치하는 구현 명세는 아니다.
0.2.0은 큰 속도 숫자, 현 도시, 여행·탐험·도장 하단 탭과 탐험 카드 6종, 실행 중 도시 도장을 구현한다. 삽화는 앱에 포함된 단순 풍경이며 도시별 랜드마크 그림은 아직 제안이다.

## 화면과 시각 체계

- 가칭: 여행 속도계. 태그라인: ‘속도를 보고, 도시를 만나고, 창밖을 발견해요’.
- 따뜻한 크림 배경 #F6F3E9, 본문 짙은 청록 #17413E, 행동 버튼 #246B64, 발견 카드 노랑 #FFCE69.
- ‘82 km/h’는 예시 숫자다. 기본은 GPS 수신 전 ‘—’; 속도가 높아져도 빨강 경고/보상/흥분 효과를 넣지 않는다.
- 기본 화면: 우리의 여행 → 현재 속도(큰 숫자와 단위) → 지금 있는 도시 → 탐험 진입 카드.
- 탐험 화면: 삽화 + 짧은 질문 한 개 + ‘찾았어요’/‘다음 카드’. 배경 추적이나 사진 업로드로 발견을 확인하지 않는다.
- 도장 화면: 만난 도시의 이름과 간단한 삽화, 이동 순서. 실제 지도나 집 주소는 표시하지 않는다.
- 한국어는 Android 기본 sans 글꼴. 속도 숫자는 80sp 전후, 도시 28~32sp, 설명 16~18sp, 터치 영역 최소 48dp.
- 화면을 내려 읽을 수 있도록 큰 글꼴/작은 화면에서 세로 스크롤, TalkBack 읽기 순서와 숫자+단위 통합 읽기 적용 권장.

## 필수 상태 디자인

- 첫 실행: ‘속도를 보려면 정확한 위치를 허용해 주세요’ + 보호자 설정 버튼.
- 권한 거부/대략적 위치: 이유 설명과 다시 허용/설정 안내. 의미 없는 0km/h 표시 금지.
- GPS 수신 중: ‘— km/h’, ‘위치를 기다리고 있어요’.
- 신호 끊김: 마지막 값을 현재 값처럼 유지하지 않고 ‘—’, ‘위치를 다시 확인하고 있어요’.
- 도시 조회 실패: 속도는 계속 표시하고 도시 카드 안에서만 실패 안내.
- 0.2.0 도장은 이번 실행 메모리에만 유지하고 새 여행/앱 종료 시 지운다. 영구 저장은 미구현이다. 시안의 ‘이 기기에만 저장’ 대신 실행 중에만 기억한다는 안내를 사용한다.
- 위치 사용·권한 설정 화면은 기본 화면의 수치보다 작게, 첫 설정 뒤에는 필요한 경우에만 강조한다.
- 음성·애니메이션은 선택 사항이고 기본 끔. 도로 주행을 게임 점수와 연결하지 않는다.

## 0.3.0 속도계 옆 나침반

속도와 나침반을 같은 흰 카드의 좌우 열에 배치한다. 속도 숫자는 좁은 화면에서 자동으로 줄인다.
나침반은 빨간 북쪽 바늘과 8방위/각도를 표시한다. ‘휴대폰 방향’ 및 ‘화면 위쪽 방향·자북 기준’으로 GPS 이동 방향과 구분한다.
센서가 없거나 정확도가 낮으면 방향 대신 안내를 표시한다. 주변 지형이 보이는 방향을 나침반만으로 판정하지 않는다.
