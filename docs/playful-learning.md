# 창밖 탐험과 도장 모으기

현재: 강·산·다리·터널·들판·도시 질문 6종을 보고 실제 풍경을 찾아 대화한다. 발견·도장·방문 횟수는 기기에 계속 보관한다.
GPS나 카메라로 보았다고 자동 판정하지 않는다. 앱을 사용하며 확인된 도시만 방문으로 기록한다.

## 다음 단계

- 라이선스/출처를 확인한 지도·지형 데이터가 있을 때 주변 강·산·다리에 맞는 질문 추천.
- ‘근처에 있다’와 ‘차창에서 보인다’를 구분. 차량 진행 방향/휴대폰 방향만으로 가시성을 단정하지 않음.
- 출처를 검토한 도시별 한 줄 이야기와 지명 유래. 즉석에서 사실을 만들어 내지 않음.
- 추가 배지는 앱 전용 창작 그림으로 사전 제작하거나 공식 로고의 판본·허락·출처를 확인해 사전 등록.

화면 체류시간·이동 속도를 점수로 삼지 않는다. 짧은 질문 → 창밖 관찰 → 가족 대화를 목표로 한다.
광고/순위/채팅/아동 계정/추적 SDK를 추가하지 않는다. 원시 좌표·경로의 영구 저장이나 백그라운드 위치 추적은 현재 범위가 아니다.
